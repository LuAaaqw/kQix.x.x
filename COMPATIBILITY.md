# Compatibility

kQIx is primarily developed for **Windows x64**. Project files are maintained for **Visual Studio 2022**, and native components use **C++20**.

The project is intended for Lua/Luau-oriented workflows. Compatibility depends on the selected release, the language dialect, and the target host. Different environments may expose different libraries, built-in functions, and runtime behavior.

## Important notes

- A feature available in a development build is not automatically a supported release feature.
- Compatibility should be evaluated with the exact kQIx release and target environment being used.
- No universal compatibility with every Lua/Luau host or third-party environment is implied.
- Official releases should identify known limitations and the environments that have been checked.

For current availability, refer to the relevant release notes. This page describes support boundaries only and does not document internal implementation details.
