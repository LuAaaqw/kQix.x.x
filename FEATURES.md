# General Capabilities

This page summarizes the user-facing scope of kQIx. Availability may vary by release and configuration.

- **Script workflow** — prepare and process supported Lua-family projects.
- **Configurable operation** — adjust available settings for different use cases.
- **Output handling** — generate and manage processed files.
- **Runtime-oriented options** — select supported behavior for the intended execution environment.
- **Validation and diagnostics** — review basic processing results and investigate reported issues.
- **Performance evaluation** — compare output size and execution behavior using repeatable samples.

This overview intentionally excludes internal architecture, implementation methods, processing details, and private development notes. It is not a complete feature specification.

For availability and limitations, see [Compatibility](COMPATIBILITY.md) and the notes accompanying each official release.
